# Система бронювання та оренди в ігровому клубі

## Опис

Проєкт описує систему для бронювання столів та оренди настільних ігор в ігровому клубі.

Користувач може переглядати доступні столи та ігрові зони, бронювати їх на певний час, а також вибирати настільні ігри для своєї сесії.

Також у системі можна залишати відгуки про столи та ігрові зони.

## Структура репозиторію

* `README.md` — короткий опис проєкту.
* `spec.md` — опис сутностей, їх атрибутів та зв'язків між ними.
* `DEFENSE.md` — обґрунтування моделі, нормалізації та внесених змін.
* `er-diagram.mmd` — код ER-діаграми у форматі Mermaid.
