# Лаба 1. ER-модель: бібліотека

## Домен
Міська бібліотека: читачі беруть у тимчасове користування фізичні примірники книг.

**Чому цей домен:** він містить усі три типи зв'язків, які потрібно показати в роботі:
1. 1:N (видавець → книги, книга → примірники, читач → видачі);
2. «чистий» M:N без власних атрибутів (книга ↔ автор, книга ↔ категорія);
3. зв'язок із власними атрибутами (читач + примірник → **Видача**: дати, повернення) — єдина асоціативна сутність.

## Структура репозиторію
 Файл         Призначення

 `er.md`      сторінка з рендером діаграми
